# Accounting System (PostgreSQL / Supabase)

## Requirements
- A compatible JDK installed.
- Visual Studio Code with the Extension Pack for Java.
- The PostgreSQL JDBC driver JAR in `lib/postgresql-42.7.14.jar`.
- A configured Supabase PostgreSQL database with the tables expected by the Java code.

## Project folders
- `src/`: Java source files.
- `bin/`: compiled `.class` files generated by VS Code.
- `lib/`: external Java libraries. Put the PostgreSQL JDBC driver here.

## PostgreSQL JDBC driver
Download the official PostgreSQL JDBC driver from:
https://jdbc.postgresql.org/download/

Place the downloaded JAR in the `lib` folder and name it `postgresql-42.7.14.jar` to match `.vscode/launch.json`.
The driver is a library, not a database. The old SQLite database file has been removed from this project.

## Configure the database connection
Set these environment variables in the environment used to launch VS Code:
- `DB_URL`: JDBC URL for your Supabase PostgreSQL database, including `?sslmode=require`.
- `DB_USER`: your database username.
- `DB_PASSWORD`: your database password.

Do not commit passwords or other secrets to GitHub. Each computer running this direct-JDBC version must have its own environment configured.

## Run
1. Open this project folder (the folder containing `src`, `bin`, `lib`, and `.vscode`) in VS Code.
2. Confirm the PostgreSQL driver JAR is present in `lib`.
3. Allow the Java extension to build the project.
4. Run the `Run Accounting App` launch configuration.

## Database schema
The app expects these PostgreSQL tables and columns:
- `public.users`: `id`, `username`, `password_hash`, `password_salt`, `iterations`
- `public.accounts`: `id`, `code`, `name`, `type`, `active`
- `public.transactions`: `id`, `transaction_date`, `description`
- `public.journal_lines`: `id`, `transaction_id`, `account_id`, `debit_centavos`, `credit_centavos`

Ensure the tables, data types, primary keys, foreign keys, and any required starter accounts exist in Supabase before running the app. The Java code currently checks connectivity and the users table; it does not automatically create the entire schema.
