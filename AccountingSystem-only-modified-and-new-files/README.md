# Accounting System

## How to Run the App

### Requirements
- Java JDK installed.
- Visual Studio Code with the Extension Pack for Java.
- PostgreSQL JDBC driver at `lib/postgresql-42.7.14.jar`.

### Steps
1. Download or clone the project from GitHub.
2. Open the `AccountingSystem` project folder in Visual Studio Code. Make sure it contains `src`, `bin`, `lib`, and `.vscode`.
3. Check that `postgresql-42.7.14.jar` is inside the `lib` folder.
4. Wait for the Java extension to finish building the project.
5. Open the **Run and Debug** panel in VS Code.
7. Select **Run Accounting App** from the launch configuration.
8. Click the green **Start Debugging** button or press `F5`.
9. The Accounting System login screen should appear.

## Every open
Double-click `AccountingSystem.jar`. No passwords or environment variables needed.

### If the App Does Not Open
- Make sure Java is installed and available in your terminal.
- Check that the PostgreSQL JDBC driver is in the correct folder.
- Verify your Supabase connection settings and internet connection.
- If the database connection times out, try another network and check whether the database port is reachable.

## Project folders
- `src/`: Java source files.
- `bin/`: compiled `.class` files generated by VS Code.
- `lib/`: external Java libraries. Put the PostgreSQL JDBC driver here.

## Filter Panel

The General Journal, Transactions and General Ledger screens share one filter panel (`AccountingFilterBar`):
- **Search**: keyword search across descriptions, accounts and amounts (press Enter or Apply). While you type, matching account names and descriptions appear below the field. Use Up and Down to pick one, Enter or a click to apply it, and Esc to close the list.
- **Account**: dropdown of the accounts shown on that screen. Each account has a short description under its name (for example, "Asset · Resources the business owns").
- **Date Range**: Today, This Week, This Month, Last 7 / 30 Days, or a custom YYYY-MM-DD range.
- **Amount Range**: minimum / maximum amount.
- **Reset Filters** clears everything; **Apply Filters** runs the filter; the **X** hides or shows the panel.
- Export CSV stays next to Apply Filters.

The Balance Sheet has no filter panel. It is an as-of-date snapshot, so use **Options > Change report date**.

## Refresh

Each screen has a **Refresh** button in its header. While the screen reloads its data, the icon spins, the button reads "Refreshing...", and it turns green and stays disabled until the reload finishes. Screens also reload when you open them. Database reads run in the background, so the window stays responsive during a reload.
